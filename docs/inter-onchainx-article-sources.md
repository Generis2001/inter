# Source notes for the Inter onchainX article

The [article](inter-onchainx-article.md) was prepared from the repository implementation reviewed on 10 November 2026. It is a product article grounded in source and project documentation; preparation did not include funded transactions or live deployment verification.

“onchainX” is used as an editorial framing for connected onchain activities, focused here on stablecoin ownership, payments, exchange, identity, and bridging. The repository does not define it as a separate protocol or product.

The draft treats fee and swap output displays as estimates. It makes no fixed exchange-rate, universal best-price, or fixed settlement-time claim. The Uniswap quoting implementation includes a fallback estimate, so the article does not describe every displayed swap quote as a live executable market quote. Portfolio totals are not used as evidence of live currency valuation: the dashboard and Assets screen use an approximate EUR/USD conversion for the Arc stablecoin estimate. cirBTC and secondary-chain balances are displayed separately and are excluded from that estimate.

The ArcNS rollout statement is time-sensitive and reflects the app's existing banner. Confirm the external protocol's deployment status before publishing a dated launch announcement. Bridge documentation records read-only route checks and mocked flow validation, with no live funded settlement performed in that validation; the article describes implemented behavior without asserting that production settlement was independently tested during drafting.
